# DVD 与蓝光

打开 DVD-Video 和未加密蓝光的 ISO 镜像或光盘文件夹（`VIDEO_TS`／`BDMV`），选择标题或播放列表，跨文件定位并预览 VOB／PGS 字幕。DVD 支持运行库可处理的 CSS 保护。

## 关键帧剪辑

支持不重新编码的剪辑导出，DVD 默认 VOB、蓝光默认 M2TS，也可为兼容轨道选择 MP4／MKV。

- 播放列表从 GOP 中间接入另一片段时，会明确拒绝跨越该衔接点的无损导出。
- 光盘 M2TS 输出会重新封装，并按导出时间轴重建时间戳。
- 单独的 VOB 不携带 IFO 字幕调色板，如需在一个文件中保留字幕颜色，可选择 MKV。

## 智能剪辑

光盘标题同样可以[智能剪辑](./smart-cut)，输出导出选项中选择的格式（DVD：VOB、MKV 或 MP4；蓝光：M2TS、MKV 或 MP4）。输出由复用器写出，不适用 TS 来源的逐包保留。

- DVD 字幕随 VOB、MKV 输出。
- 蓝光 PGS 字幕随 M2TS、MKV 输出：切点处正在显示的字幕通过回看约 30 秒恢复（这段范围内找不到该字幕的起点时，视为切点处没有字幕），每段结束时清屏。

## DVD 的定位精度

DVD 跳转只精确到 VOBU，并且每次跳转都会重建时间戳，预览显示的时间可能与实际相差。程序按标记时看到的画面（附近关键帧加相对偏移）记录切点，导出时从第一个切点之前一段顺序读取，找到的正是标记时看到的画面。

## 暂不支持

- 播放项之间轨道布局变化的播放列表暂未验证，轨道选择以打开标题时探测到的轨道为准。
- 光盘菜单、受保护的蓝光，以及将光盘来源保存到工程。
