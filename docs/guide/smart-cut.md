# 智能剪辑

开启工具栏右侧的 **智能剪辑** 开关后，起止点可以落在任意画面上，不必对齐关键帧。导出时只重新编码起点、终点附近的少量画面，中间部分直接复制原始压缩数据；音频和字幕按数据包复制，不重新编码。起止点恰好落在可衔接的关键帧上时，那一侧不重新编码。

## 使用步骤

1. 打开视频后，按下工具栏右侧的 **智能剪辑** 开关。
2. 通过时间轴、导航条或 <kbd>,</kbd>／<kbd>.</kbd> 键逐帧定位，标记起点和终点。在导航条上滚动滚轮可每格移到上一个或下一个关键帧；也可在设置中改为按帧或按秒移动（见[播放与预览](./playback#鼠标滚轮)）。
3. 保存、加入导出队列或合并导出；导出窗口会显示重新编码与直接复制的进度。

开关状态会被记住并随工程保存，加入导出队列的片段会保留当时选择的模式。如果已有片段的边界不在关键帧上，程序会列出这些片段，需调整边界后才能切回关键帧剪辑。

## 特点

- **逐帧定位**：导航条逐帧显示缩略图，可用 <kbd>,</kbd>／<kbd>.</kbd> 键前后移动一帧；播放后暂停标记时不再吸附到关键帧。
- **广播素材**：支持部分没有 IDR 帧的 H.264 和 HEVC 开放 GOP 录制。程序会检查衔接处能否直接复制，需要时重新编码前导画面；无法安全衔接则停止导出并提示原因。
- **逐行刷新的素材**：全片没有完整关键帧、只靠逐行刷新恢复画面的 H.264 与 MPEG-2（常见于卫星回传，如带杜比 E 的回传信号）也可以智能剪辑。直接复制的部分从刷新入口开始，开头几秒的画面与原片略有差别，经过一个刷新周期（通常不到 5 秒）后与原片完全一致。
- **导出进度**：导出窗口用计划条显示重新编码（橙色）与直接复制（绿色）的分布、当前阶段，以及无需重新编码的比例。
- **保存与合并**：支持保存单个片段、批量导出队列，以及同一文件的多片段合并。

## 支持的视频

| 编码 | 支持范围 |
| --- | --- |
| H.264 | Baseline、Main、High、High 4:2:2，8／10 位，含隔行 |
| HEVC | Main、Main 10、4:2:2 |
| MPEG-2 | Main、Simple、4:2:2，含开放 GOP 与隔行 |
| AV1 | Main（仅 MP4／MKV） |
| VP9 | Profile 0／2（仅 MP4／MKV） |

重新编码的画面保留 HDR10、HLG 及单层杜比视界 Profile 5／8.1。

## 输出格式

- TS／M2TS 来源输出同一格式；MP4、MKV 等可重封装的来源输出 MP4 或 MKV。
- **TS 检测**：TS／M2TS 直接复制部分保留源传输包，原片已有的连续计数器跳号、TEI、PCR／PTS 跳变等问题仍可能出现在导出文件中，可用 [TS 快速检查](./ts-tools)查看。多节目 TS 只输出预览所在的节目。
- **DVD 与蓝光标题**：输出导出选项中选择的格式（DVD：VOB、MKV 或 MP4；蓝光：M2TS、MKV 或 MP4），由复用器写出。详见 [DVD 与蓝光](./discs#智能剪辑)。

## 限制

素材不支持时开关会禁用，悬停可查看原因（如 4:4:4、HDR10+、软下拉）。每段重新编码最多 60 秒；找不到可衔接的关键帧时，会在写文件前明确报错。重新编码的画面与原片存在细微差别。官方发布包内置的运行库已包含所需的编码器。
