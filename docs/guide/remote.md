# 远程剪辑

在一台电脑上运行 TSCutter.GUI 作为宿主，其他设备用浏览器登录，就能远程打开素材、标记切点和导出片段。每个账号有独立的剪辑进程和输出目录，素材目录只读。

## 启动与登录

1. 在宿主机打开 **工具 → 远程剪辑**，选择已存在的默认素材目录和默认输出目录。两者不能相同，也不能互相包含。
2. 在 **用户管理** 中添加用户名和密码。各账号可以使用默认目录，也可以分别指定路径。
3. 启动服务，复制访问链接，将链接和账号信息交给使用者。使用者在浏览器打开链接并登录，每个账号同一时间允许一个浏览器控制。

**允许局域网中的设备访问** 默认开启，取消勾选后仅限本机访问。服务运行时，宿主机主窗口的编辑区锁定。关闭远程设置窗口不会停止服务；点击 **停止远程剪辑**，或确认关闭宿主程序，会停止全部远程工作区。

## 目录与账号

在 **用户管理** 中，对素材或输出目录取消 **使用默认目录**，选择路径并保存。

- 素材目录只读，任何输出目录都不能与已配置的素材目录重叠。
- 使用同一输出目录的账号共享其中的文件；需要独立访问时，输出目录应互不重叠、互不包含。
- 同名导出不会覆盖已有文件，遇到冲突请修改文件名或输出位置。保存和导出目录选择窗口中的 **新建文件夹** 可在分配的输出目录内创建并进入子文件夹。
- 远程工作区支持文件素材和工程，光盘来源请在桌面版打开。

修改运行中工作区的素材或输出目录需要确认，会丢失该工作区未保存的编辑。只有对应账号的工作区会停止，其浏览器可保留登录并重新连接。正在导出、载入素材或有子窗口打开时，需先完成或关闭相应操作，才能应用目录修改。

默认目录、连接设置、账号和账号偏好保存在应用数据目录下的 `TSCutter.GUI/remote-editing.json`，密码保存为带盐哈希。关闭设置窗口会保存默认目录，无需先启动服务；账号目录修改需点击保存按钮应用。

## 工作区与登录状态

各账号拥有独立的剪辑进程、编辑状态和偏好。

- 浏览器断开或退出登录后，工作区保留。重置密码会撤销该账号的登录并断开连接，工作区同样保留。
- 停止工作区、禁用或删除账号、停止服务或退出宿主程序，会丢失未保存的编辑和远程截图模板；已保存的工程和导出文件保留在磁盘上。
- 工作区按需启动，默认最多保留 4 个工作进程，可在启动服务前调整。断开的空白工作区闲置 30 分钟后回收；已载入素材、有片段、导出队列或打开子窗口的工作区保留到手动停止。资源占满时，可以停止不再需要的工作区。

宿主程序保持运行、访问地址不变且登录有效时，同一浏览器可通过书签重新进入。默认素材目录、默认输出目录和访问地址不变时，停止并重新启动服务也会保留登录；重启宿主程序后需要重新登录。

## 浏览器操作

使用 **打开** 选择素材，按桌面版的方式标记切点和保存片段，结果写入该账号分配的输出目录。

悬浮的控制面板分为 **画面**、**操作**、**连接** 三页：手机上从底部展开，电脑上显示为右下角浮层，收起后保留一个小按钮。点击浮层外或按 Esc 收起时，不会误点到底下的编辑器。在 **操作** 页可以开启声音或显示手机键盘，只有开启声音时才传输音频。

**画质** 默认 **清晰**，**分辨率** 默认自动：按访问设备的像素密度选择，同时受画质档位的尺寸上限限制。文字模糊时，可以选择清晰画质或手动提高分辨率。

- 720p、1080p、1440p 和 4K 控制输出像素上限并保持工作区比例；手动选择分辨率后，画质只影响编码质量和码率，不改变输出尺寸。最高为 3840 × 2160，竖屏为 2160 × 3840。
- **画面比例** 默认 **跟随屏幕**，也可以选择 16:9 使用宽屏工作区。界面缩放跟随访问设备的显示密度和浏览器的页面缩放。
- 降低分辨率可以减轻宿主的编码负担，降低画质可以减少带宽需求。

手机默认开启 **触控板模式**：

- 单指滑动移动光标，轻点为左键，双指轻点为右键，双指平行滑动为滚动，单指长按后滑动为拖动。
- 虚拟光标和电脑鼠标会显示文本、链接、调整大小等光标样式；可拖动的区域会在左上角提示长按操作。
- 双指捏合缩放画面，点击 **画面适应窗口** 恢复完整画面。
- 触摸工作区不会自动弹出键盘，需要输入时，在控制面板的 **操作** 页点击 **显示键盘**。
- 关闭触控板模式后可以直接触摸操作，画面放大时单指滑动可平移。

## 视频与网络

视频通过 WebSocket 传输，默认使用软件编码的 H.264，最高 60 帧。在控制面板的 **画面** 页可以改用针对屏幕内容优化的 AV1，或使用 JPEG 图像传输。所选模式需要宿主与浏览器都支持，实际帧率和清晰度取决于分辨率、宿主性能、浏览器和网络状况。

- H.264 根据播放回执调整码率和采集频率；网络拥塞时不会自动切换所选的视频模式或分辨率档位。
- H.264 和 AV1 模式下，页面进入后台时暂停采集，返回后刷新画面。
- 遇到可恢复的播放或传输错误时，浏览器保留最后的画面，最多连续重试所选视频流 3 次，工作区和编辑状态不受影响。无法恢复时，**连接** 页会显示具体原因，可以点击 **重试所选视频模式**，或手动选择其他模式。

服务使用 HTTP，其他设备访问时需要允许宿主网页端口的 TCP 入站流量。默认监听 IPv4；需要 IPv6 时，允许局域网访问并勾选 **启用 IPv6 监听**（默认关闭），此时在同一端口同时监听 IPv4 和 IPv6，地址列表会包含可用的 IPv6 地址。IPv6 网址需要方括号，例如 `http://[2001:db8::1]:5360/`。

## 命令行单用户模式

```sh
TSCutterGUI --web-ui <端口> <素材目录> <导出目录> [--lan [--ipv6]]
```

启动单用户服务，使用终端输出的配对码登录，不使用桌面端的账号。不加 `--lan` 时只监听 IPv4 回环地址；`--lan` 允许 IPv4 局域网访问，`--lan --ipv6` 同时启用 IPv4 和 IPv6。在终端输入 `pair` 可以生成新的配对码，同时撤销已配对浏览器的授权并断开当前连接。
