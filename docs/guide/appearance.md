# 外观与语言

## 主题

提供 Windows Classic、XP、7、8、10、11 六个主题系列，可分别设置深浅配色；macOS 还提供带原生标题栏的 macOS 外观。通过 **视图 → 主题** 快速切换系列，或在 **工具 → 设置** 中分别选择浅色、深色配色；**自动检测** 会跟随系统外观。

Aero 与 Windows 11 截图展示实色回退外观，实际模糊或 Mica 材质取决于平台支持。窗口圆角取决于宿主系统：Windows 11（Build 22000 及以上）上的 Aero 和 Windows 11 主题保留圆角，较旧 Windows 上这两个主题使用直角窗口。

## macOS

在 macOS 上，所有主题都提供系统原生菜单栏；Windows 系列主题同时保留窗口内菜单栏，维持完整外观，macOS 外观在系统菜单可用时隐藏窗口内菜单。两处菜单共用命令、快捷键、多语言和勾选状态。

macOS 外观只在 macOS 上出现在主题列表中，保留系统红黄绿、窗口圆角和阴影，标题融入内容顶部，应用菜单移到系统菜单栏，并在可用时使用侧栏模糊材质；控件配色沿用 Windows 11 的 Fluent 风格，工具栏使用独立的单色矢量图标。

## 界面语言

界面支持简体中文、繁体中文和英文。默认 **自动检测语言**，跟随系统语言；也可在 **工具 → 设置** 的“常规”页取消自动检测，手动选择 **当前语言**。
