# 播放与预览

## 连续播放

点击播放按钮或按 <kbd>空格</kbd>，从当前画面开始播放，再次按下暂停。右键点击播放按钮，选择 **播放选中片段**，可只播放该片段，到结尾自动暂停。拖动时间轴或点击缩略图后，原在播放则从新位置继续，否则保持暂停。DVD 和蓝光标题也支持播放。

多音轨文件可在预览上方选择播放音轨，默认选中第一条可解码音轨。不支持解码的音轨（如 AV3A）仍显示在列表中并置灰；没有可解码音轨时，视频会无声播放。杜比 E 音轨按声道组分别列出，可以直接试听。音量按钮与滑块只影响预览，不改变导出内容。

全片没有 I 帧、只靠逐行刷新恢复画面的 MPEG-2 素材（常见于卫星回传）也能正常预览和定位。

关键帧模式下，暂停后标记边界会吸附到不晚于当前画面的兼容关键帧，并显示对齐后的画面；智能剪辑模式按实际显示帧标记。

### 全屏

双击视频、点击全屏按钮，或选择 **视图 → 全屏播放** 进入全屏。<kbd>F11</kbd> 切换全屏，macOS 也可使用 <kbd>Control</kbd> + <kbd>Command</kbd> + <kbd>F</kbd>；按 <kbd>Esc</kbd> 返回编辑界面。播放时静置三秒后控制栏自动隐藏，移动鼠标即可显示；暂停时保持可见。

### 渲染与帧率

播放优先使用 GPU 处理转色、缩放和 HDR 映射，不支持时自动改用 CPU。状态栏显示实际呈现帧率：绿色表示解码和显示均能跟上片源且未丢帧，黄色表示流畅度不足，红色表示帧率低于片源的 70%。性能不足时可能跳帧以保持播放进度。

### 播放性能测试

工具栏的 **工具 → 播放性能测试…** 使用当前文件、轨道、位置与预览设置；菜单栏的 **工具 → 检查与分析 → 播放性能测试…** 则选择其他文件。

测试分别显示解码、画面处理和播放的 FPS，并标明实际使用的 CPU 或 GPU 路径。CPU 画面转换较慢，不一定影响走 GPU 路径的播放，应结合实际播放结果判断。可调整输出尺寸，比较不同窗口大小下的表现。测试静音运行，期间暂停主窗口播放；结果仅供判断所测片段和设置下的性能。

## 预览选项

在 **工具 → 设置 → 视频** 中配置新打开文件默认使用的 HDR 到 SDR 映射和硬解偏好；状态栏的切换仅临时影响当前文件。

- **SDR 映射**入口仅在识别出 HDR 画面时显示。打开关键帧总览、图集和画面搜索时，也会使用当前映射状态。
- **H/W / S/W** 显示当前解码模式。Windows/macOS 上，当前视频及设备支持硬解时可点击切换；硬解不可用或失败回退软解后禁用。
- 切换映射或解码器会保持当前显示帧和剪辑边界。

### 解码设备

在 **工具 → 设置 → 视频** 中选择硬解使用的显卡（勾选 **优先使用硬件解码** 后可选）。默认 **自动** 由系统选择。Windows 上每张显卡只列出一次（虚拟显示器和远程桌面适配器不列出），适合核显加独显、默认显卡不支持某种编码的电脑。

指定的显卡用于预览、逐帧定位和播放；它无法解码当前视频时改用软解；显卡已被移除时改用自动选择，并保留已保存的选择，直到重新修改。播放时如果解码显卡不是绘制窗口的显卡，画面会经系统内存复制。macOS 始终由系统选择 GPU，Linux 版不使用硬解，因此这两个平台只有 **自动**。修改对之后打开的视频和开始的播放生效。

### 音频波形

导航条下方用一条与节目带等高的平滑曲线显示正在播放的音轨在导航条范围内的响度，每张缩略图下方是从这一画面到下一张之间的声音；曲线只反映响度起伏，不画逐帧细节。

波形按导航条显示的完整范围分段读取，每段最多 30 秒，当前位置附近优先显示；播放时暂停更新。音轨不能解码时不显示波形条。可在 **视图 → 音频波形** 或 **设置 → 预览** 中关闭，关闭后停止读取波形数据。

### 音频延迟

在预览上方的音轨选择框右侧勾选 **延迟** 并输入毫秒数，正数让声音推后，负数提前（±5 秒以内，右键可重置为 0）。不勾选时不生效，导出仍原样复制，数值保留。

- 预览播放与导航条波形会按延迟平移，便于对照画面调整。
- 延迟作用于当前节目的全部音轨，不只是预览选中的一条；多节目 TS 中其他节目的声音保持不变。
- 是否启用与数值随工程保存，加入导出队列的任务记下当时生效的延迟。
- 导出时只改写音轨的时间戳：关键帧模式的 TS 仍按原包复制，包数、连续计数（CC）、PCR 和其他 PID 都不变，只改音频 PES 头中的时间戳；智能剪辑与 MP4/MKV 重封装同样只平移音轨。
- 片段按画面切分，所以延迟会让片段一端少一小段声音（等于延迟的长度）。偏移越大，部分硬件播放器越可能丢掉开头的声音。

### 导航条缩略图大小

在 **工具 → 设置 → 预览** 中可选小、中（默认）、大三档。缩略图越大，导航条越高，同样宽度内显示的画面越少；修改后立即生效。

### 鼠标滚轮

在 **工具 → 设置 → 预览** 中设置滚轮定位的单位（关键帧、帧或秒）、每格移动的数量、按住 <kbd>Shift</kbd> 时的数量（默认 10，与 <kbd>Shift</kbd>+方向键相同）和滚动方向。

- 按帧只在智能剪辑模式下生效，其他模式按关键帧移动。
- 按秒时，智能剪辑模式落在目标时间的那一帧，关键帧剪辑模式与点击时间轴相同落在附近的关键帧，且至少移动一个关键帧。
- 预览画面的滚轮可改为定位（按住 <kbd>Ctrl</kbd>，macOS 为 <kbd>⌘</kbd>，仍缩放画面）；时间轴的滚轮可设为定位或在放大后左右平移，<kbd>Ctrl</kbd>/<kbd>⌘</kbd> 加滚轮始终缩放时间轴。

### 快捷键

**工具 → 设置 → 快捷键** 列出当前平台的全部键盘与鼠标操作，可按操作或按键搜索；暂不支持修改按键。
