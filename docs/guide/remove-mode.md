# 删除模式

删除模式用来把广告、片头片尾等标记为要去掉的范围，再将其余内容合并为一个文件。它可与关键帧剪辑、智能剪辑两种方式搭配使用。

## 使用步骤

1. 按下工具栏中“智能剪辑”左侧的 **删除模式** 开关。开关状态会被记住，下次启动沿用。
2. 像标记片段一样标记要删除的范围：起点是第一个被删除的画面，终点是恢复播放的画面（终点本身保留）。只标记起点、不标记终点时，删除到文件结尾。
3. 选中要删除的范围，点击 **导出删除后的视频**，其余部分合并为一个文件。

## 显示与统计

删除范围在时间轴、缩略图条和片段卡片上以红色显示（恢复播放的终点画面不标红）。片段卡片显示删除的大小（需要重新封装的文件显示“不适用”），底部汇总显示删除的段数、导出后保留的时长和预估大小，导出完成后改为输出文件的实际大小。

## 注意事项

- 关键帧剪辑模式下删除范围的起止都落在关键帧上，开放 GOP 素材在删除起点处可能少几帧前导画面；智能剪辑模式可精确到任意画面。
- 删除模式下不能单独保存、加入队列或分别导出片段。
- 删除模式随工程保存（工程版本 6，旧版程序无法打开）。
