# 快速開始

TSCutter.GUI 是一款跨平台影片剪輯工具，支援快速的關鍵影格剪下和精確到影格的智慧剪輯，同時整合媒體混流、MPEG-TS 分析與修復功能。適用於 **Windows、macOS 和 Linux**。

## 下載

從 [GitHub Releases](https://github.com/nilaoda/TSCutter.GUI/releases/latest) 下載對應平台的最新 Beta 版。釋出包涵蓋 Windows、macOS 和 Linux 的 x64 與 Arm64：Linux 版需要 glibc 2.39 或更新版本（例如 Ubuntu 24.04），macOS 版需要 macOS 14 或更新版本。

官方釋出包已將 [FFmpeg](https://github.com/nilaoda/FFmpegSharedLibraries) 靜態連結進程式，無需另行安裝執行庫；Windows 版就是一個可執行檔，附帶第三方聲明。

::: warning 處理器需求
x64 電腦的 CPU 需支援 SSE4.2 和 POPCNT（x86-64-v2）。不支援的有 Intel Core 2、2013 年以前的 Atom，以及 AMD Athlon 64、Phenom、Athlon II、A 系列 3000 和 E 系列（Bobcat）；在這些 CPU 上程式開啟後會直接結束，請使用 0.7.1 或更早的版本。Apple 晶片和 Arm64 裝置不受影響。
:::

::: tip macOS
如果應用因隔離屬性被攔截，可在終端執行：

```sh
xattr -dr com.apple.quarantine TSCutter.GUI.app
```
:::

## 四步上手

1. 開啟影片，或將檔案拖入視窗。
2. 定位畫面，標記片段起止點。需要按影格剪下時開啟 **智慧剪輯**；需要去掉片段時開啟 **刪除**。
3. 儲存單個片段、合併選取片段，或匯出刪除所選範圍後的內容。
4. 儲存 `.tscut` 專案，之後繼續編輯。

最近開啟過的影片、光碟和專案可以從 **檔案 → 最近開啟** 再次開啟，最多保留 10 項，前 9 項可按數字鍵直接選擇。重新開啟光碟時會預先選取上次的標題；找不到的檔案會標出，點擊時詢問是否移除。可在 **工具 → 設定 → 一般** 中關閉記錄或清除清單。

開啟檔案和儲存檔案的對話方塊分別記住上次所在的資料夾，重新啟動後仍然有效：開啟影片、光碟、專案和各工具的輸入檔案時，從上次開啟的資料夾開始；儲存片段、匯出、截圖和各 TS 工具的輸出時，從上次匯出的資料夾開始，沒有記錄時使用來源檔案所在的資料夾。可在 **工具 → 設定 → 匯出** 中把“儲存和匯出對話方塊預設開啟”改為來源檔案所在的資料夾。記住的資料夾暫時無法使用（例如行動硬碟未連接）時改用下一個選擇，重新連接後照常使用。

## 兩種剪輯方式

| 模式 | 處理方式 |
| --- | --- |
| **關鍵影格剪輯**（預設） | 在相容的關鍵影格處剪下，不重新編碼音影片。 |
| **智慧剪輯** | 按影格選擇起止點，只重新編碼切點附近的影片，中間部分直接複製；音訊和字幕不重新編碼。 |

開啟 **刪除**，即可把廣告、片頭片尾等標記為要去掉的範圍，再將其餘內容合併匯出。刪除模式可與兩種剪輯方式搭配使用。

## 支援的格式

- 剪輯 TS/M2TS，重封裝匯出 MP4/MOV 和 MKV/WebM。
- 預覽 FFmpeg 支援的通用影片格式。
- 開啟 DVD-Video 與未加密藍光的 ISO 映象或光碟資料夾。

## 自動儲存與復原

程式會定時把尚未儲存的片段、匯出佇列和專案設定寫入應用程式資料目錄中的復原檔案，不會改動專案檔案和來源檔案。程式當機或斷電後，下次啟動時會列出可以復原的工作（來源檔案、專案、片段與佇列數量及儲存時間），可以選擇復原、刪除或下次再詢問；找不到來源檔案時可以重新指定位置。復原的內容標為未儲存，標題列顯示“已復原”。正常結束、儲存專案或選擇放棄變更後，復原檔案會被刪除。

可在 **工具 → 設定 → 一般** 中關閉“自動儲存復原資訊”或調整儲存間隔（30 秒到 10 分鐘，預設 1 分鐘）。同時執行多個應用程式執行個體時，各自儲存復原檔案。光碟來源不能儲存為專案，也不在復原範圍內。

## 工作進度

匯出、匯出佇列、TS 檢測與修復、媒體混流、縮圖總覽等耗時操作的進度會顯示在 Windows 工作列按鈕或 macOS Dock 圖示上。匯出佇列顯示整個佇列的進度，同時進行多項操作時顯示合計進度，操作失敗時進度列變為紅色。可在 **工具 → 設定 → 一般** 中關閉“在工作列或 Dock 圖示上顯示進度”；Linux 不顯示。
