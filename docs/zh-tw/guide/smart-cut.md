# 智慧剪輯

開啟工具列右側的 **智慧剪輯** 開關後，起止點可以落在任意畫面上，不必對齊關鍵影格。匯出時只重新編碼起點、終點附近的少量畫面，中間部分直接複製原始壓縮資料；音訊和字幕按封包複製，不重新編碼。起止點恰好落在可銜接的關鍵影格上時，那一側不重新編碼。

## 使用步驟

1. 開啟影片後，按下工具列右側的 **智慧剪輯** 開關。
2. 透過時間軸、導覽列或 <kbd>,</kbd>／<kbd>.</kbd> 鍵逐影格定位，標記起點和終點。在導覽列上滾動滾輪可每格移到上一個或下一個關鍵影格；也可在設定中改為按影格或按秒移動（見[播放與預覽](./playback#滑鼠滾輪)）。
3. 儲存、加入匯出佇列或合併匯出；匯出視窗會顯示重新編碼與直接複製的進度。

開關狀態會被記住並隨專案儲存，加入匯出佇列的片段會保留當時選擇的模式。如果已有片段的邊界不在關鍵影格上，程式會列出這些片段，需調整邊界後才能切回關鍵影格剪輯。

## 特點

- **逐影格定位**：導覽列逐影格顯示縮圖，可用 <kbd>,</kbd>／<kbd>.</kbd> 鍵前後移動一個影格；播放後暫停標記時不再吸附到關鍵影格。
- **廣播素材**：支援部分沒有 IDR 影格的 H.264 和 HEVC 開放 GOP 錄製。程式會檢查銜接處能否直接複製，需要時重新編碼前導畫面；無法安全銜接則停止匯出並提示原因。
- **匯出進度**：匯出視窗用計劃條顯示重新編碼（橙色）與直接複製（綠色）的分佈、目前階段，以及無需重新編碼的比例。
- **儲存與合併**：支援儲存單個片段、批次匯出佇列，以及同一檔案的多片段合併。

## 支援的影片

| 編碼 | 支援範圍 |
| --- | --- |
| H.264 | Baseline、Main、High、High 4:2:2，8／10 位，含交錯式 |
| HEVC | Main、Main 10、4:2:2 |
| MPEG-2 | Main、Simple，含開放 GOP 與交錯式 |
| AV1 | Main（僅 MP4／MKV） |
| VP9 | Profile 0／2（僅 MP4／MKV） |

重新編碼的畫面保留 HDR10、HLG 及單層杜比視界 Profile 5／8.1。

## 輸出格式

- TS／M2TS 來源輸出同一格式；MP4、MKV 等可重封裝的來源輸出 MP4 或 MKV。
- **TS 檢測**：TS／M2TS 直接複製部分保留源傳輸包，原片已有的連續計數器跳號、TEI、PCR／PTS 跳變等問題仍可能出現在匯出檔案中，可用 [TS 快速檢查](./ts-tools)檢視。多節目 TS 只輸出預覽所在的節目。
- **DVD 與藍游標題**：輸出匯出選項中選擇的格式（DVD：VOB、MKV 或 MP4；藍光：M2TS、MKV 或 MP4），由複用器寫出。詳見 [DVD 與藍光](./discs#智慧剪輯)。

## 限制

素材不支援時開關會停用，懸停可檢視原因（如 4:4:4、HDR10+、軟下拉）。每段重新編碼最多 60 秒；找不到可銜接的關鍵影格時，會在寫檔案前明確報錯。重新編碼的畫面與原片存在細微差別。官方釋出包內建的執行庫已包含所需的編碼器。
