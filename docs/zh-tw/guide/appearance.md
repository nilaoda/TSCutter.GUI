# 外觀與語言

## 主題

提供 Windows Classic、XP、7、8、10、11 六個主題系列，可分別設定深淺配色；macOS 還提供帶原生標題欄的 macOS 外觀。透過 **檢視 → 主題** 快速切換系列，或在 **工具 → 設定** 中分別選擇淺色、深色配色；**自動偵測** 會跟隨系統外觀。

Aero 與 Windows 11 截圖展示實色回退外觀，實際模糊或 Mica 材質取決於平台支援。視窗圓角取決於宿主系統：Windows 11（Build 22000 及以上）上的 Aero 和 Windows 11 主題保留圓角，較舊 Windows 上這兩個主題使用直角視窗。

## macOS

在 macOS 上，所有主題都提供系統原生選單欄；Windows 系列主題同時保留視窗內選單欄，維持完整外觀，macOS 外觀在系統選單可用時隱藏視窗內選單。兩處選單共用命令、快速鍵、多語言和勾選狀態。

macOS 外觀只在 macOS 上出現在主題列表中，保留系統紅黃綠、視窗圓角和陰影，標題融入內容頂部，應用選單移到系統選單欄，並在可用時使用側欄模糊材質；控制元件配色沿用 Windows 11 的 Fluent 風格，工具列使用獨立的單色向量圖示。

## 介面語言

介面支援簡體中文、繁體中文和英文。預設 **自動偵測語言**，跟隨系統語言；也可在 **工具 → 設定** 的“一般”頁取消自動偵測，手動選擇 **目前語言**。
