# 遠端剪輯

在一台電腦上執行 TSCutter.GUI 作為主機，其他裝置用瀏覽器登入，就能遠端開啟素材、標記切點和匯出片段。每個帳號有獨立的剪輯程序，只能存取分配給它的資料夾。

## 啟動與登入

1. 在主機開啟 **工具 → 遠端剪輯**，選擇已存在的預設開啟資料夾和預設儲存資料夾。兩個資料夾可以相同，也可以互相包含。
2. 在 **使用者管理** 中新增使用者名稱和密碼。各帳號可以使用全域預設資料夾，也可以單獨指定資料夾。
3. 啟動服務，複製存取連結，將連結和帳號資訊交給使用者。使用者在瀏覽器開啟連結並登入，每個帳號同一時間只允許一個瀏覽器控制。

**允許區域網路中的裝置存取** 預設開啟，取消勾選後僅限本機存取。服務執行時，主機主視窗的編輯區會鎖定。關閉遠端設定視窗不會停止服務；點擊 **停止遠端剪輯**，或確認關閉主機程式，會停止全部遠端工作區。

## 目錄與帳號

在 **使用者管理** 中，對 **預設開啟資料夾** 或 **預設儲存資料夾** 取消 **使用全域預設**，選擇路徑並儲存。

- 帳號只能存取分配的這兩個資料夾及其子資料夾，範圍內都可以開啟和儲存檔案。
- 使用同一資料夾的帳號可以修改其中的檔案；需要獨立存取時，請為各帳號分配互不重疊、互不包含的資料夾。
- 開啟、儲存和選擇資料夾視窗可以在素材資料夾與輸出資料夾之間切換，兩個資料夾相同時只顯示 **工作資料夾**。修復或匯出的檔案可以直接重新開啟繼續剪輯，專案儲存在任一資料夾後都可以直接儲存更新。
- 手動儲存遇到同名檔案時會詢問是否取代。媒體匯出在檢查通過後先刪除舊檔再寫入，匯出失敗時無法還原舊檔；專案、剪輯點、報告和圖片先完整寫入暫存檔再取代。自動產生的輸出會自動改名或報錯，不會靜默覆蓋已有檔案。
- 儲存視窗中選取已有檔案可以沿用並修改它的名稱；**新增資料夾** 在目前所在的資料夾建立子資料夾。
- 遠端工作區支援檔案素材和專案，光碟來源請在桌面版開啟。

修改執行中工作區的資料夾需要確認，會遺失該工作區尚未儲存的編輯。只有對應帳號的工作區會停止，其瀏覽器可保留登入並重新連線。正在匯出、載入素材或有子視窗開啟時，需先完成或關閉相應操作，才能套用目錄修改。

預設目錄、連線設定、帳號和帳號偏好儲存在應用程式資料目錄下的 `TSCutter.GUI/remote-editing.json`，密碼以加鹽雜湊儲存。關閉設定視窗會儲存預設目錄，無需先啟動服務；帳號目錄的修改需點擊儲存按鈕套用。

## 工作區與登入狀態

各帳號擁有獨立的剪輯程序、編輯狀態和偏好。

- 瀏覽器中斷連線或登出後，工作區保留。重設密碼會撤銷該帳號的登入並中斷連線，工作區同樣保留。
- 停止工作區、停用或刪除帳號、停止服務或結束主機程式，會遺失尚未儲存的編輯和遠端截圖範本；已儲存的專案和匯出檔案保留在磁碟上。
- 工作區按需啟動，預設最多保留 4 個工作程序，可在啟動服務前調整。中斷連線的空白工作區閒置 30 分鐘後回收；已載入素材、有片段、匯出佇列或開啟子視窗的工作區保留到手動停止。資源用盡時，可以停止不再需要的工作區。

主機程式保持執行、存取位址不變且登入有效時，同一瀏覽器可透過書籤重新進入。預設開啟資料夾、預設儲存資料夾和存取位址不變時，停止並重新啟動服務也會保留登入；重新啟動主機程式後需要重新登入。

## 瀏覽器操作

使用 **開啟** 選擇素材，按桌面版的方式標記切點和儲存片段，結果預設寫入該帳號的預設儲存資料夾，也可以在儲存視窗中選擇任一分配的資料夾。

浮動的控制面板分為 **畫面**、**操作**、**連線** 三頁：手機上從底部展開，電腦上顯示為右下角浮層，收起後保留一個小按鈕。點擊浮層外或按 Esc 收起時，不會誤點到底下的編輯器。在 **操作** 頁可以開啟聲音或顯示手機鍵盤，只有開啟聲音時才傳輸音訊。

**畫質** 預設 **清晰**，**解析度** 預設自動：按存取裝置的像素密度選擇，同時受畫質檔位的尺寸上限限制。文字模糊時，可以選擇清晰畫質或手動提高解析度。

- 720p、1080p、1440p 和 4K 控制輸出像素上限並保持工作區比例；手動選擇解析度後，畫質只影響編碼品質和位元速率，不改變輸出尺寸。最高為 3840 × 2160，直向為 2160 × 3840。
- **畫面比例** 預設 **跟隨螢幕**，也可以選擇 16:9 使用寬螢幕工作區。介面縮放跟隨存取裝置的顯示密度和瀏覽器的頁面縮放。
- 降低解析度可以減輕主機的編碼負擔，降低畫質可以減少頻寬需求。

手機預設開啟 **觸控板模式**：

- 單指滑動移動游標，輕點為左鍵，雙指輕點為右鍵，雙指平行滑動為捲動，單指長按後滑動為拖曳。
- 虛擬游標和電腦滑鼠會顯示文字、連結、調整大小等游標樣式；可拖曳的區域會在左上角提示長按操作。
- 雙指捏合縮放畫面，點擊 **畫面符合視窗** 恢復完整畫面。
- 觸碰工作區不會自動彈出鍵盤，需要輸入時，在控制面板的 **操作** 頁點擊 **顯示鍵盤**。
- 關閉觸控板模式後可以直接觸控操作，畫面放大時單指滑動可平移。

## 影片與網路

影片透過 WebSocket 傳輸，預設使用軟體編碼的 H.264，最高 60 影格。在控制面板的 **畫面** 頁可以改用針對螢幕內容最佳化的 AV1，或使用 JPEG 影像傳輸。所選模式需要主機與瀏覽器都支援，實際影格率和清晰度取決於解析度、主機效能、瀏覽器和網路狀況。

- H.264 根據播放回報調整位元速率和擷取頻率；網路壅塞時不會自動切換所選的影片模式或解析度檔位。
- H.264 和 AV1 模式下，頁面進入背景時暫停擷取，返回後重新整理畫面。
- 遇到可恢復的播放或傳輸錯誤時，瀏覽器保留最後的畫面，最多連續重試所選影片串流 3 次，工作區和編輯狀態不受影響。無法恢復時，**連線** 頁會顯示具體原因，可以點擊 **重試所選影片模式**，或手動選擇其他模式。

服務使用 HTTP，其他裝置存取時需要允許主機網頁連接埠的 TCP 輸入流量。預設監聽 IPv4；需要 IPv6 時，允許區域網路存取並勾選 **啟用 IPv6 監聽**（預設關閉），此時在同一連接埠同時監聽 IPv4 和 IPv6，位址清單會包含可用的 IPv6 位址。IPv6 網址需要方括號，例如 `http://[2001:db8::1]:5360/`。

## 命令列單一使用者模式

```sh
TSCutterGUI --web-ui <連接埠> <素材目錄> <匯出目錄> [--lan [--ipv6]]
```

啟動單一使用者服務，使用終端機輸出的配對碼登入，不使用桌面版的帳號。不加 `--lan` 時只監聽 IPv4 迴路位址；`--lan` 允許 IPv4 區域網路存取，`--lan --ipv6` 同時啟用 IPv4 和 IPv6。在終端機輸入 `pair` 可以產生新的配對碼，同時撤銷已配對瀏覽器的授權並中斷目前的連線。
