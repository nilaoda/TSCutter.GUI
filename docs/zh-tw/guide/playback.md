# 播放與預覽

## 連續播放

點選播放按鈕或按 <kbd>空格</kbd>，從目前畫面開始播放，再次按下暫停。右鍵點選播放按鈕，選擇 **播放選取片段**，可只播放該片段，到結尾自動暫停。拖動時間軸或點選縮圖後，原在播放則從新位置繼續，否則保持暫停。DVD 和藍游標題也支援播放。

多音軌檔案可在預覽上方選擇播放音軌，預設選取第一條可解碼音軌。不支援解碼的音軌（如 AV3A）仍顯示在列表中並置灰；沒有可解碼音軌時，影片會無聲播放。音量按鈕與滑塊隻影響預覽，不改變匯出內容。

關鍵影格模式下，暫停後標記邊界會吸附到不晚於目前畫面的相容關鍵影格，並顯示對齊後的畫面；智慧剪輯模式按實際顯示影格標記。

### 全螢幕

雙擊影片、點選全螢幕按鈕，或選擇 **檢視 → 全螢幕播放** 進入全螢幕。<kbd>F11</kbd> 切換全螢幕，macOS 也可使用 <kbd>Control</kbd> + <kbd>Command</kbd> + <kbd>F</kbd>；按 <kbd>Esc</kbd> 返回編輯介面。播放時靜置三秒後控制欄自動隱藏，移動滑鼠即可顯示；暫停時保持可見。

### 渲染與影格率

播放優先使用 GPU 處理轉色、縮放和 HDR 對映，不支援時自動改用 CPU。狀態列顯示實際呈現影格率：綠色表示解碼和顯示均能跟上片源且未丟影格，黃色表示流暢度不足，紅色表示影格率低於片源的 70%。效能不足時可能跳影格以保持播放進度。

### 播放效能測試

工具列的 **工具 → 播放效能測試…** 使用目前檔案、軌道、位置與預覽設定；選單欄的 **工具 → 檢查與分析 → 播放效能測試…** 則選擇其他檔案。

測試分別顯示解碼、畫面處理和播放的 FPS，並標明實際使用的 CPU 或 GPU 路徑。CPU 畫面轉換較慢，不一定影響走 GPU 路徑的播放，應結合實際播放結果判斷。可調整輸出尺寸，比較不同視窗大小下的表現。測試靜音執行，期間暫停主視窗播放；結果僅供判斷所測片段和設定下的效能。

## 預覽選項

在 **工具 → 設定 → 視訊** 中配置新開啟檔案預設使用的 HDR 到 SDR 對映和硬解偏好；狀態列的切換僅臨時影響目前檔案。

- **SDR 對映**入口僅在識別出 HDR 畫面時顯示。開啟關鍵影格總覽、圖集和畫面搜尋時，也會使用目前對映狀態。
- **H/W / S/W** 顯示目前解碼模式。Windows/macOS 上，目前影片及裝置支援硬解時可點選切換；硬解不可用或失敗回退軟解後停用。
- 切換對映或解碼器會保持目前顯示影格和剪輯邊界。

### 解碼裝置

在 **工具 → 設定 → 視訊** 中選擇硬解使用的顯示卡（勾選 **優先使用硬體解碼** 後可選）。預設 **自動** 由系統選擇。Windows 上每張顯示卡只列出一次（虛擬顯示器和遠端桌面介面卡不列出），適合核顯加獨顯、預設顯示卡不支援某種編碼的電腦。

指定的顯示卡用於預覽、逐影格定位和播放；它無法解碼目前影片時改用軟解；顯示卡已被移除時改用自動選擇，並保留已儲存的選擇，直到重新修改。播放時如果解碼顯示卡不是繪製視窗的顯示卡，畫面會經系統記憶體複製。macOS 始終由系統選擇 GPU，Linux 版不使用硬解，因此這兩個平台只有 **自動**。修改對之後開啟的影片和開始的播放生效。

### 音訊波形

導覽列下方用一條與節目帶等高的平滑曲線顯示正在播放的音軌在導覽列範圍內的響度，每張縮圖下方是從這一畫面到下一張之間的聲音；曲線只反映響度起伏，不畫逐影格細節。

波形按導覽列顯示的完整範圍分段讀取，每段最多 30 秒，目前位置附近優先顯示；播放時暫停更新。音軌不能解碼時不顯示波形條。可在 **檢視 → 音訊波形** 或 **設定 → 預覽** 中關閉，關閉後停止讀取波形資料。

### 音訊延遲

在預覽上方的音軌選擇框右側勾選 **延遲** 並輸入毫秒數，正數讓聲音推後，負數提前（±5 秒以內，右鍵可重置為 0）。不勾選時不生效，匯出仍原樣複製，數值保留。

- 預覽播放與導覽列波形會按延遲平移，便於對照畫面調整。
- 延遲作用於目前節目的全部音軌，不只是預覽選取的一條；多節目 TS 中其他節目的聲音保持不變。
- 是否啟用與數值隨專案儲存，加入匯出佇列的任務記下當時生效的延遲。
- 匯出時只改寫音軌的時間戳：關鍵影格模式的 TS 仍按原包複製，包數、連續計數（CC）、PCR 和其他 PID 都不變，只改音訊 PES 頭中的時間戳；智慧剪輯與 MP4/MKV 重封裝同樣只平移音軌。
- 片段按畫面切分，所以延遲會讓片段一端少一小段聲音（等於延遲的長度）。偏移越大，部分硬體播放器越可能丟掉開頭的聲音。

### 導覽列縮圖大小

在 **工具 → 設定 → 預覽** 中可選小、中（預設）、大三檔。縮圖越大，導覽列越高，同樣寬度內顯示的畫面越少；修改後立即生效。

### 滑鼠滾輪

在 **工具 → 設定 → 預覽** 中設定滾輪定位的單位（關鍵影格、影格或秒）、每格移動的數量、按住 <kbd>Shift</kbd> 時的數量（預設 10，與 <kbd>Shift</kbd>+方向鍵相同）和滾動方向。

- 按影格只在智慧剪輯模式下生效，其他模式按關鍵影格移動。
- 按秒時，智慧剪輯模式落在目標時間的那一影格，關鍵影格剪輯模式與點選時間軸相同落在附近的關鍵影格，且至少移動一個關鍵影格。
- 預覽畫面的滾輪可改為定位（按住 <kbd>Ctrl</kbd>，macOS 為 <kbd>⌘</kbd>，仍縮放畫面）；時間軸的滾輪可設為定位或在放大後左右平移，<kbd>Ctrl</kbd>/<kbd>⌘</kbd> 加滾輪始終縮放時間軸。

### 快速鍵

**工具 → 設定 → 快速鍵** 列出目前平台的全部鍵盤與滑鼠操作，可按操作或按鍵搜尋；暫不支援修改按鍵。
