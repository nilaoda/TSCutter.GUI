# 章節與節目表

檔案或光碟標題帶章節（MP4、MKV、DVD、藍光），或電視錄製帶 EPG（DVB 現在/下一個節目表）時，時間軸上方顯示節目帶，按章節或“現在播出”的節目分段，狀態列顯示章節數或節目數。兩者都有時顯示章節。節目帶隨時間軸縮放，播放頭所在的段突出顯示。

## 檢視與跳轉

- 懸停可檢視章節的起止和時長，或節目的排期（含日期）、在錄製中的範圍和簡介；單擊跳到這一段的開始。
- 右鍵可跳到章節（節目）開始或結束，或 **按章節新增片段**（**按節目新增片段**）。新增的片段以章節名或節目名命名，沒有章節名時使用“章節 N”，起止按目前剪輯模式確定。
- 工具列 **資訊** 視窗的“章節”或“EPG”標籤頁列出全部章節，或讀到的全部節目（含播出日期與時段）及其是否在本錄製中；單擊章節或錄製中的節目即可跳轉。

## EPG 的讀取方式

EPG 只讀取檔案開頭附近，開頭沒有就視為沒有 EPG，不掃描整個檔案；跳轉到其他位置並停留片刻後，會在該處再探測一次。

::: warning 時間僅供參考
EPG 按排期時刻切換，實際播出往往早或晚幾分鐘。按節目新增的片段在卡片上提示“EPG 時間，請核對起訖”，重新標記起點或終點後提示消失。
:::

## 關閉節目帶

可在 **檢視 → 章節/節目帶** 或 **工具 → 設定 → 預覽** 中關閉節目帶：關閉後完全不讀取章節和 EPG，節目帶、狀態列的數量和 **資訊** 視窗的“章節”/“EPG”標籤頁都不顯示；重新開啟時為目前檔案重新讀取。關閉也可避免在網路或慢速磁碟上讀取 EPG。
