# 剪輯與匯出

## 主剪輯介面

1. 開啟 TS、M2TS、MP4 或 MKV 檔案，或將檔案拖入視窗。
2. 瀏覽或縮放時間軸，新增片段並標記起點和終點。
3. 儲存目前片段、加入匯出佇列，或選擇多個片段進行合併。
4. 需要稍後繼續時，從“檔案”選單儲存專案；之後開啟 `.tscut` 專案即可恢復剪輯和匯出佇列。仍在增長的原始檔可繼續使用；如果已儲存部分的校驗不透過，則會拒絕恢復。

<Screenshot name="editor" alt="主剪輯介面" />

多節目、多影片軌道或帶內嵌字幕的檔案，可在預覽上方選擇節目、影片和字幕。字幕預設關閉，首次選擇時在後臺讀取，可隨時關閉或改選其他軌道。切換節目或影片軌道會在確認後清空目前剪輯與撤銷歷史，已加入匯出佇列的任務保留原節目和軌道選擇。

對於多節目 TS，“僅匯出目前節目”保留所選節目的全部軌道，適用於儲存、合併及新加入佇列的任務。

::: info 關鍵影格模式下的 TS 匯出
普通 TS/M2TS 單段匯出在保留全部節目且不補節目表時，直接複製原始位元組。多段合併和重封裝匯出需要調整部分結構或時間戳，不是位元組級原樣複製。
:::

## 匯出結果

儲存片段、合併匯出和刪除模式匯出完成後，會顯示結果視窗：輸出檔案的位置、大小、耗時與平均速度、片段內容、智慧剪輯的重新編碼比例和 TS 檢測結論，並可開啟檔案、在資料夾中顯示或複製摘要。

- 匯出失敗時視窗顯示錯誤說明；取消匯出不會彈窗，未寫完的檔案會被刪除。
- 勾選“以後不再顯示”或在設定中關閉後，成功匯出不再彈窗，失敗仍會提示。
- 匯出佇列等批次匯出不顯示該視窗，結果可在“匯出記錄”中檢視。

## 片段標註

點選片段卡片上的 **鉛筆圖示**，編輯名稱、備註和顏色，支援撤銷/重做。時間軸以對應顏色顯示片段，懸停可檢視名稱和備註。加入匯出佇列時，會儲存當時的標註和剪輯邊界。

## 輸出檔名

在 **工具 → 設定 → 匯出** 中設定檔名模板，適用於單片段儲存、逐段批次匯出及新加入佇列的片段。預設模板為 `{source}_({start}-{end})`；合併輸出的檔名另行指定。

| 佔位符 | 含義 |
| --- | --- |
| `{source}` | 不含副檔名的原始檔名 |
| `{name}` | 片段名稱；為空時按序號使用 `clip001` 等名稱 |
| `{index}` | 目前片段在列表中的位置，補齊為三位數字 |
| `{start}`、`{end}` | 起止時間，如 `00.00.10.000`；未設終點時使用影片時長 |

例如 `{source}_{index}_{name}` 可生成 `Recording_001_Opening.ts`。程式自動新增所選的 TS/M2TS/MP4/MKV 副檔名並替換檔名中的非法字元；批次匯出遇到重名或已有檔案時追加 `_2`、`_3` 等字尾。模板隻影響之後的匯出建議，已入隊的輸出路徑保持所選值。
