# 刪除模式

刪除模式用來把廣告、片頭片尾等標記為要去掉的範圍，再將其餘內容合併為一個檔案。它可與關鍵影格剪輯、智慧剪輯兩種方式搭配使用。

## 使用步驟

1. 按下工具列中“智慧剪輯”左側的 **刪除模式** 開關。開關狀態會被記住，下次啟動沿用。
2. 像標記片段一樣標記要刪除的範圍：起點是第一個被刪除的畫面，終點是恢復播放的畫面（終點本身保留）。只標記起點、不標記終點時，刪除到檔案結尾。
3. 選取要刪除的範圍，點選 **匯出刪除後的視訊**，其餘部分合併為一個檔案。

## 顯示與統計

刪除範圍在時間軸、縮圖條和片段卡片上以紅色顯示（恢復播放的終點畫面不標紅）。片段卡片顯示刪除的大小（需要重新封裝的檔案顯示“不適用”），底部彙總顯示刪除的段數、匯出後保留的時長和預估大小，匯出完成後改為輸出檔案的實際大小。

## 注意事項

- 關鍵影格剪輯模式下刪除範圍的起止都落在關鍵影格上，開放 GOP 素材在刪除起點處可能少幾影格前導畫面；智慧剪輯模式可精確到任意畫面。
- 刪除模式下不能單獨儲存、加入佇列或分別匯出片段。
- 刪除模式隨專案儲存（專案版本 6，舊版程式無法開啟）。
