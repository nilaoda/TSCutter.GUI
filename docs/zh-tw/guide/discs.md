# DVD 與藍光

開啟 DVD-Video 和未加密藍光的 ISO 映象或光碟資料夾（`VIDEO_TS`／`BDMV`），選擇標題或播放列表，跨檔案定位並預覽 VOB／PGS 字幕。DVD 支援執行庫可處理的 CSS 保護。

## 關鍵影格剪輯

支援不重新編碼的剪輯匯出，DVD 預設 VOB、藍光預設 M2TS，也可為相容軌道選擇 MP4／MKV。

- 播放列表從 GOP 中間接入另一片段時，會明確拒絕跨越該銜接點的無損匯出。
- 光碟 M2TS 輸出會重新封裝，並按匯出時間軸重建時間戳。
- 單獨的 VOB 不攜帶 IFO 字幕調色盤，如需在一個檔案中保留字幕顏色，可選擇 MKV。

## 智慧剪輯

光碟標題同樣可以[智慧剪輯](./smart-cut)，輸出匯出選項中選擇的格式（DVD：VOB、MKV 或 MP4；藍光：M2TS、MKV 或 MP4）。輸出由複用器寫出，不適用 TS 來源的逐包保留。

- DVD 字幕隨 VOB、MKV 輸出。
- 藍光 PGS 字幕隨 M2TS、MKV 輸出：切點處正在顯示的字幕透過回看約 30 秒恢復（這段範圍內找不到該字幕的起點時，視為切點處沒有字幕），每段結束時清屏。

## DVD 的定位精度

DVD 跳轉只精確到 VOBU，並且每次跳轉都會重建時間戳，預覽顯示的時間可能與實際相差。程式按標記時看到的畫面（附近關鍵影格加相對偏移）記錄切點，匯出時從第一個切點之前一段順序讀取，找到的正是標記時看到的畫面。

## 暫不支援

- 播放項之間軌道佈局變化的播放列表暫未驗證，軌道選擇以開啟標題時探測到的軌道為準。
- 光碟選單、受保護的藍光，以及將光碟來源儲存到專案。
