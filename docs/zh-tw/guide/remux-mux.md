# 重封裝與混流

## MP4 / MKV 重封裝剪輯與合併

以下說明適用於關鍵影格剪輯模式。智慧剪輯會重新編碼切點附近的影片畫面，詳見[智慧剪輯](./smart-cut)。

- 在「MP4 / MKV 匯出設定」中選擇輸出封裝和保留軌道，保留原始檔中的軌道順序、語言、名稱及預設/強制標記。
- 支援單片段、批次匯出及同一檔案多片段合併；合併時選取片段的重疊區間僅保留一次。
- 影片按關鍵影格剪輯並保留標記的終點影格，音訊按壓縮封包邊界剪輯；相容的文本字幕（包括 MP4 內嵌 mov_text 和 MKV ASS）與章節會裁剪並重設時間。MKV 還支援 PGS 圖形字幕，會補齊剪輯起點的顯示狀態並在終點清屏；MKV 可保留附件，MP4 可保留封面。
- 複製音影片壓縮封包和編解碼配置，保留封裝可承載的色彩、HDR 靜態資訊及杜比視界配置；碼流中的動態後設資料隨壓縮封包保留。
- 自動檢查編碼和軌道相容性；無法安全剪輯或合併時明確提示。

::: info 不重新編碼，但並非位元組級無損
關鍵影格模式下，MP4/MKV 匯出不重新編碼音影片，但容器結構、時間戳及後設資料會重新寫入，檔案雜湊和大小會變化；可保留的後設資料欄位取決於輸出封裝。MP4 保留封面時使用標準後設資料欄位，其他 MP4 輸出可寫入自定義後設資料。
:::

MKV 文字字幕預設快速定位，回看每段起點前約 30 秒，可能遺漏更早開始且跨越起點的文字字幕；需要完整保留時可在匯出設定中關閉。PGS 圖形字幕會單獨恢復所需的顯示狀態。

失敗或取消時保留已有目標檔案，並清理臨時輸出。

## 媒體混流

透過 **工具 → 合併與混流 → 媒體混流** 將多個影片、音訊和字幕檔案的軌道封裝到一個檔案。支援勾選軌道、拖動調整輸出順序，以及編輯軌道名稱、語言程式碼、預設／強制標記和時間偏移。可輸出 MKV、MP4、TS 和 M2TS，不重新編碼音影片。

- HEVC 的 MP4 輸出使用 hvc1，杜比視界使用 dvh1，同時保留必要的影格內解碼引數。
- MP4 可開啟 **為網路播放最佳化**，預設關閉；開啟後將索引移到檔案開頭，完成時需要在輸出檔案內額外搬移一次資料。
- 正偏移表示延後，負偏移表示提前，行為類似 FFmpeg `-itsoffset`。零點前的時間戳由輸出封裝處理：MP4 透過編輯列表跳過開頭內容，MKV、TS／M2TS 可能整體平移時間軸。
- **以最短軌道為準** 預設關閉；開啟後按偏移後最早結束的音影片軌道截止，也可選擇計入字幕，封面和附件不參與計算。音影片按壓縮封包邊界截止，字幕顯示時長裁到終點；未提供時長的軌道需先讀取封包確認結束位置。
- 相容字幕直接複製，其餘文字字幕自動轉為 MP4 的 mov_text 或 MKV 的 SRT，開始前會標出轉換方式及可能的樣式損失。圖形字幕不轉為文字，不相容軌道需取消勾選或更換封裝。官方執行庫已包含字幕轉換所需的編碼器。
- TS／M2TS 不保留軌道名稱及預設／強制標記。

失敗或取消時保留已有目標檔案，並刪除臨時輸出。發生錯誤時可展開檢視處理階段及 FFmpeg 詳細原因。
