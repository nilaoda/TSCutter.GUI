# TS 工具

可以直接從“工具”選單開啟任意工具。每個工具都會在獨立視窗中引導選擇所需的一個或多個原始檔，無需先在主剪輯介面載入檔案。

## 工具一覽

| 工具 | 用途 |
| --- | --- |
| **TS 原始流截取** | 按位元組範圍或包範圍直接提取 TS 資料。 |
| **TS 快速檢查** | 掃描同步丟失、TEI、連續計數器、PES、PCR、PTS、DTS、音影片漂移和位元速率變化，並可匯出文本報告。 |
| **TS 封包檢視器** | 逐包檢視 188 位元組 TS 或 192 位元組 M2TS 資料，按包編號、偏移或 PID 導航，並將解析欄位與 Hex 位元組高亮關聯。M2TS 可檢視附加頭和到達時間戳。 |
| **TS ES 擷取器** | 選擇一條或多條軌道，去除 TS 和 PES 封裝後分別輸出原始影片、音訊、字幕或資料負載。 |
| **TS 串流過濾器** | 保留選定 PID，或按服務拆分檔案，同時重建必要的節目表和業務表。 |
| **TS 串流編輯器** | 刪除軌道或節目、調整標識及 PID，並編輯服務或語言資訊，同時保留原始媒體編碼。 |
| **TS 時間軸修復** | 分析並安全校正受支援的 PCR 和時間戳不連續問題，不掩蓋傳輸錯誤或真實丟包。 |
| **TS 多來源修復** | 比較同一訊號源、同一時間段的相容錄製，在安全匹配的前提下使用正常的 TS 包、PES 或 ES 資料修復損壞區域及大段缺失。 |
| **TS 二進位合併** | 按順序追加 TS 分片、去除完全相同的二進位制重疊，或合併僅連續計數器不同的同源重疊錄製。 |

## 匯出時的 TS 檢測

匯出 TS/M2TS 時，檢測隨寫出同時進行，無需匯出後重新掃描；結果顯示在匯出結果視窗和“匯出記錄”中。

## 包長支援

支援 188 位元組 TS 和 192 位元組 M2TS 無損剪輯，按實際包結構識別；M2TS 預設輸出為 `.m2ts`，保留附加頭。

| 工具 | 188 位元組 TS | 192 位元組 M2TS |
| --- | :---: | :---: |
| 快速檢查（含批次）、原始擷取、包檢視器、節目拆分、ES 提取 | ✓ | ✓ |
| 時間軸修復、流過濾、流編輯器、多源修復、二進位制合併 | ✓ | — |

不支援的包長會明確提示。
