# 使用指南

[English](USAGE.md) | **简体中文** · [返回首页](../README_CN.md)

## 主剪辑界面

1. 打开 TS、M2TS、MP4 或 MKV 文件，或将文件拖入窗口。
2. 浏览或缩放时间轴，添加片段并标记起点和终点。
3. 保存当前片段、加入导出队列，或选择多个片段进行合并。
4. 需要稍后继续时，从“文件”菜单保存工程；之后打开 `.tscut` 工程即可恢复剪辑和导出队列。仍在增长的源文件可继续使用；如果已保存部分的校验不通过，则会拒绝恢复。

多节目、多视频轨道或带内嵌字幕的文件，可在预览上方选择节目、视频和字幕。字幕默认关闭，首次选择时在后台读取，可随时关闭或改选其他轨道。切换节目或视频轨道会在确认后清空当前剪辑与撤销历史，已加入导出队列的任务保留原节目和轨道选择。

对于多节目 TS，“仅导出当前节目”保留所选节目的全部轨道，适用于保存、合并及新加入队列的任务。使用新版功能保存的工程，旧版程序可能无法打开。

关键帧模式下，普通 TS/M2TS 单段导出在保留全部节目且不补节目表时，直接复制原始字节。多段合并和重封装导出需要调整部分结构或时间戳，不是字节级原样复制。

保存片段、合并导出和删除模式导出完成后，会显示结果窗口：输出文件的位置、大小、耗时与平均速度、片段内容、智能剪辑的重新编码比例和 TS 检测结论，并可打开文件、在文件夹中显示或复制摘要。导出失败时窗口显示错误说明；取消导出不会弹窗，未写完的文件会被删除。勾选“以后不再显示”或在设置中关闭后，成功导出不再弹窗，失败仍会提示。导出队列等批量导出不显示该窗口，结果可在“导出记录”中查看。

## 删除模式

1. 按下工具栏中“智能剪辑”左侧的 **删除模式** 开关。开关状态会被记住，下次启动沿用。
2. 像标记片段一样标记要删除的范围：起点是第一个被删除的画面，终点是恢复播放的画面（终点本身保留）。只标记起点、不标记终点时，删除到文件结尾。
3. 选中要删除的范围，点击 **导出删除后的视频**，其余部分合并为一个文件。

删除范围在时间轴、缩略图条和片段卡片上以红色显示（恢复播放的终点画面不标红）。片段卡片显示删除的大小（需要重新封装的文件显示“不适用”），底部汇总显示删除的段数、导出后保留的时长和预估大小，导出完成后改为输出文件的实际大小。

关键帧剪辑模式下删除范围的起止都落在关键帧上，开放 GOP 素材在删除起点处可能少几帧前导画面；智能剪辑模式可精确到任意画面。

删除模式下不能单独保存、加入队列或分别导出片段。删除模式随工程保存（工程版本 6，旧版程序无法打开）。光盘文件只支持关键帧剪辑。

## 智能剪辑模式

1. 打开视频后，按下工具栏右侧的 **智能剪辑** 开关。
2. 通过时间轴、导航条或 **,**／**.** 键逐帧定位，标记起点和终点。在导航条上滚动滚轮可每格移到上一个或下一个关键帧；也可在设置中改为按帧或按秒移动（见“预览选项”）。
3. 保存、加入导出队列或合并导出；导出窗口会显示重新编码与直接复制的进度。

开关状态会被记住并随工程保存，加入导出队列的片段会保留当时选择的模式。如果已有片段的边界不在关键帧上，程序会列出这些片段，需调整边界后才能切回关键帧剪辑。

## 连续播放

点击播放按钮或按 **空格**，从当前画面开始播放，再次按下暂停。右键点击播放按钮，选择 **播放选中片段**，可只播放该片段，到结尾自动暂停。拖动时间轴或点击缩略图后，原在播放则从新位置继续，否则保持暂停。DVD 和蓝光标题也支持播放。

多音轨文件可在预览上方选择播放音轨，默认选中第一条可解码音轨。不支持解码的音轨（如 AV3A）仍显示在列表中并置灰；没有可解码音轨时，视频会无声播放。音量按钮与滑块只影响预览，不改变导出内容。

双击视频、点击全屏按钮，或选择 **视图 → 全屏播放** 进入全屏。**F11** 切换全屏，macOS 也可使用 **Control + Command + F**；按 **Esc** 返回编辑界面。播放时静置三秒后控制栏自动隐藏，移动鼠标即可显示；暂停时保持可见。

关键帧模式下，暂停后标记边界会吸附到不晚于当前画面的兼容关键帧，并显示对齐后的画面；智能剪辑模式按实际显示帧标记。

播放优先使用 GPU 处理转色、缩放和 HDR 映射，不支持时自动改用 CPU。状态栏显示实际呈现帧率：绿色表示解码和显示均能跟上片源且未丢帧，黄色表示流畅度不足，红色表示帧率低于片源的 70%。性能不足时可能跳帧以保持播放进度。

### 播放性能测试

工具栏的 **工具 → 播放性能测试…** 使用当前文件、轨道、位置与预览设置；菜单栏的 **工具 → 检查与分析 → 播放性能测试…** 则选择其他文件。

测试分别显示解码、画面处理和播放的 FPS，并标明实际使用的 CPU 或 GPU 路径。CPU 画面转换较慢，不一定影响走 GPU 路径的播放，应结合实际播放结果判断。可调整输出尺寸，比较不同窗口大小下的表现。测试静音运行，期间暂停主窗口播放；结果仅供判断所测片段和设置下的性能。

## 预览选项

在 **工具 → 设置** 中配置新打开文件默认使用的 HDR 到 SDR 映射和硬解偏好；状态栏的切换仅临时影响当前文件。

- **SDR 映射**入口仅在识别出 HDR 画面时显示。打开关键帧总览、图集和画面搜索时，也会使用当前映射状态。
- **H/W / S/W** 显示当前解码模式。Windows/macOS 上，当前视频及设备支持硬解时可点击切换；硬解不可用或失败回退软解后禁用。
- 切换映射或解码器会保持当前显示帧和剪辑边界。
- **音频波形**：导航条下方用一条与节目带等高的平滑曲线显示正在播放的音轨在导航条范围内的响度，每张缩略图下方是从这一画面到下一张之间的声音；曲线只反映响度起伏，不画逐帧细节。波形按导航条显示的完整范围分段读取，每段最多 30 秒，当前位置附近优先显示；播放时暂停更新。音轨不能解码时不显示波形条。可在 **视图 → 音频波形** 或 **设置 → 预览** 中关闭，关闭后停止读取波形数据。
- **音频延迟**：在预览上方的音轨选择框右侧勾选 **延迟** 并输入毫秒数，正数让声音推后，负数提前（±5 秒以内，右键可重置为 0）。不勾选时不生效，导出仍原样复制，数值保留。预览播放与导航条波形会按延迟平移，便于对照画面调整。延迟作用于当前节目的全部音轨，不只是预览选中的一条；多节目 TS 中其他节目的声音保持不变。是否启用与数值随工程保存，加入导出队列的任务记下当时生效的延迟。导出时只改写音轨的时间戳：关键帧模式的 TS 仍按原包复制，包数、连续计数（CC）、PCR 和其他 PID 都不变，只改音频 PES 头中的时间戳；智能剪辑与 MP4/MKV 重封装同样只平移音轨。片段按画面切分，所以延迟会让片段一端少一小段声音（等于延迟的长度）。偏移越大，部分硬件播放器越可能丢掉开头的声音。
- **导航条缩略图大小**：在 **工具 → 设置 → 预览** 中可选小、中（默认）、大三档。缩略图越大，导航条越高，同样宽度内显示的画面越少；修改后立即生效。
- **鼠标滚轮**：在 **工具 → 设置 → 预览** 中设置滚轮定位的单位（关键帧、帧或秒）、每格移动的数量、按住 Shift 时的数量（默认 10，与 Shift+方向键相同）和滚动方向。按帧只在智能剪辑模式下生效，其他模式按关键帧移动；按秒时，智能剪辑模式落在目标时间的那一帧，关键帧剪辑模式与点击时间轴相同落在附近的关键帧，且至少移动一个关键帧。预览画面的滚轮可改为定位（按住 Ctrl，macOS 为 ⌘，仍缩放画面）；时间轴的滚轮可设为定位或在放大后左右平移，Ctrl/⌘ 加滚轮始终缩放时间轴。
- **工具 → 设置 → 快捷键** 列出当前平台的全部键盘与鼠标操作，可按操作或按键搜索；暂不支持修改按键。

## 片段标注与输出命名

点击片段卡片上的 **铅笔图标**，编辑名称、备注和颜色，支持撤销/重做。时间轴以对应颜色显示片段，悬停可查看名称和备注。加入导出队列时，会保存当时的标注和剪辑边界。

在 **工具 → 设置 → 导出** 中设置文件名模板，适用于单片段保存、逐段批量导出及新加入队列的片段。默认模板为 `{source}_({start}-{end})`；合并输出的文件名另行指定。

| 占位符 | 含义 |
| --- | --- |
| `{source}` | 不含扩展名的源文件名 |
| `{name}` | 片段名称；为空时按序号使用 `clip001` 等名称 |
| `{index}` | 当前片段在列表中的位置，补齐为三位数字 |
| `{start}`、`{end}` | 起止时间，如 `00.00.10.000`；未设终点时使用视频时长 |

例如 `{source}_{index}_{name}` 可生成 `Recording_001_Opening.ts`。程序自动添加所选的 TS/M2TS/MP4/MKV 扩展名并替换文件名中的非法字符；批量导出遇到重名或已有文件时追加 `_2`、`_3` 等后缀。模板只影响之后的导出建议，已入队的输出路径保持所选值。

## 章节与录制节目（EPG）

文件或光盘标题带章节（MP4、MKV、DVD、蓝光），或电视录制带 EPG（DVB 现在/下一个节目表）时，时间轴上方显示节目带，按章节或“现在播出”的节目分段，状态栏显示章节数或节目数。两者都有时显示章节。节目带随时间轴缩放，播放头所在的段突出显示。

- 悬停可查看章节的起止和时长，或节目的排期（含日期）、在录制中的范围和简介；单击跳到这一段的开始。
- 右键可跳到章节（节目）开始或结束，或 **按章节添加片段**（**按节目添加片段**）。添加的片段以章节名或节目名命名，没有章节名时使用“章节 N”，起止按当前剪辑模式确定。
- EPG 只读取文件开头附近，开头没有就视为没有 EPG，不扫描整个文件；跳转到其他位置并停留片刻后，会在该处再探测一次。EPG 按排期时刻切换，实际播出往往早或晚几分钟。按节目添加的片段在卡片上提示“EPG 时间，请核对起止”，重新标记起点或终点后提示消失。
- 工具栏 **信息** 窗口的“章节”或“EPG”标签页列出全部章节，或读到的全部节目（含播出日期与时段）及其是否在本录制中；单击章节或录制中的节目即可跳转。

## 独立 TS 工具

可以直接从“工具”菜单打开任意工具。每个工具都会在独立窗口中引导选择所需的一个或多个源文件，无需先在主剪辑界面加载文件。

## 智能剪辑

开启工具栏右侧的 **智能剪辑** 开关后，起止点可以落在任意画面上，不必对齐关键帧。导出时只重新编码起点、终点附近的少量画面，中间部分直接复制原始压缩数据；音频和字幕按数据包复制，不重新编码。起止点恰好落在可衔接的关键帧上时，那一侧不重新编码。

- **逐帧定位**：导航条逐帧显示缩略图，可用 **,**／**.** 键前后移动一帧；播放后暂停标记时不再吸附到关键帧。
- **支持的视频**：H.264（Baseline、Main、High、High 4:2:2，8／10 位，含隔行）、HEVC（Main、Main 10、4:2:2）、MPEG-2（Main、Simple，含开放 GOP 与隔行）、AV1（Main）和 VP9（Profile 0／2）。重新编码的画面保留 HDR10、HLG 及单层杜比视界 Profile 5／8.1。
- **广播素材**：支持部分没有 IDR 帧的 H.264 和 HEVC 开放 GOP 录制。程序会检查衔接处能否直接复制，需要时重新编码前导画面；无法安全衔接则停止导出并提示原因。
- **输出格式**：TS／M2TS 来源输出同一格式；MP4、MKV 等可重封装的来源输出 MP4 或 MKV。AV1、VP9 只支持 MP4／MKV。
- **DVD 与蓝光标题**：光盘标题同样可以智能剪辑，输出导出选项中选择的格式（DVD：VOB、MKV 或 MP4；蓝光：M2TS、MKV 或 MP4）。输出由复用器写出，不适用下文“TS 检测”所说的逐包保留。DVD 每次跳转都会重建时间戳，所选画面按附近关键帧与相对偏移记录，导出时从第一个切点之前一段顺序读取，找到的正是所选画面。DVD 字幕随 VOB、MKV 输出。蓝光 PGS 字幕随 M2TS、MKV 输出：切点处正在显示的字幕通过回看约 30 秒恢复（这段范围内找不到该字幕的起点时，视为切点处没有字幕），每段结束时清屏。
- **TS 检测**：TS／M2TS 直接复制部分保留源传输包，原片已有的连续计数器跳号、TEI、PCR／PTS 跳变等问题仍可能出现在导出文件中，可用 TS 快速检查查看。多节目 TS 只输出预览所在的节目。
- **导出进度**：导出窗口用计划条显示重新编码（橙色）与直接复制（绿色）的分布、当前阶段，以及无需重新编码的比例。
- **保存与合并**：支持保存单个片段、批量导出队列，以及同一文件的多片段合并。

素材不支持时开关会禁用，悬停可查看原因（如 4:4:4、HDR10+、软下拉）。每段重新编码最多 60 秒；找不到可衔接的关键帧时，会在写文件前明确报错。重新编码的画面与原片存在细微差别。官方发布包内置的运行库已包含所需的编码器。实现思路见[智能剪辑实现说明](智能剪辑实现说明.md)。

## MP4 / MKV 重封装剪辑与合并

以下说明适用于关键帧剪辑模式。智能剪辑会重新编码切点附近的视频画面，详见上文。

- 在「MP4 / MKV 导出设置」中选择输出封装和保留轨道，保留源文件中的轨道顺序、语言、名称及默认/强制标记。
- 支持单片段、批量导出及同文件多片段合并；合并时选中片段的重叠区间仅保留一次。
- 视频按关键帧剪辑并保留标记的终点帧，音频按压缩包边界剪辑；兼容的文本字幕（包括 MP4 内嵌 mov_text 和 MKV ASS）与章节会裁剪并重设时间。MKV 还支持 PGS 图形字幕，会补齐剪辑起点的显示状态并在终点清屏；MKV 可保留附件，MP4 可保留封面。
- 复制音视频压缩包和编解码配置，保留封装可承载的色彩、HDR 静态信息及杜比视界配置；码流中的动态元数据随压缩包保留。
- 自动检查编码和轨道兼容性；无法安全剪辑或合并时明确提示。

**关键帧模式下，MP4/MKV 导出不重新编码音视频，但并非字节级无损。** 容器结构、时间戳及元数据会重新写入，文件哈希和大小会变化；可保留的元数据字段取决于输出封装。MP4 保留封面时使用标准元数据字段，其他 MP4 输出可写入自定义元数据。

MKV 文字字幕默认快速定位，回看每段起点前约 30 秒，可能遗漏更早开始且跨越起点的文字字幕；需要完整保留时可在导出设置中关闭。PGS 图形字幕会单独恢复所需的显示状态。

失败或取消时保留已有目标文件，并清理临时输出。

## 媒体混流

通过 **工具 → 合并与混流 → 媒体混流** 将多个视频、音频和字幕文件的轨道封装到一个文件。支持勾选轨道、拖动调整输出顺序，以及编辑轨道名称、语言代码、默认／强制标记和时间偏移。可输出 MKV、MP4、TS 和 M2TS，不重新编码音视频。

HEVC 的 MP4 输出使用 hvc1，杜比视界使用 dvh1，同时保留必要的帧内解码参数。

MP4 可开启 **为网络播放优化**，默认关闭；开启后将索引移到文件开头，完成时需要在输出文件内额外搬移一次数据。

正偏移表示延后，负偏移表示提前，行为类似 FFmpeg `-itsoffset`。零点前的时间戳由输出封装处理：MP4 通过编辑列表跳过开头内容，MKV、TS／M2TS 可能整体平移时间轴。

**以最短轨道为准** 默认关闭；开启后按偏移后最早结束的音视频轨道截止，也可选择计入字幕，封面和附件不参与计算。音视频按压缩包边界截止，字幕显示时长裁到终点；未提供时长的轨道需先读取数据包确认结束位置。

兼容字幕直接复制，其余文字字幕自动转为 MP4 的 mov_text 或 MKV 的 SRT，开始前会标出转换方式及可能的样式损失。图形字幕不转为文字，不兼容轨道需取消勾选或更换封装。官方运行库已包含字幕转换所需的编码器。

TS／M2TS 不保留轨道名称及默认／强制标记。

失败或取消时保留已有目标文件，并删除临时输出。发生错误时可展开查看处理阶段及 FFmpeg 详细原因。

## DVD 与蓝光

打开 DVD-Video 和未加密蓝光的 ISO 镜像或光盘文件夹（`VIDEO_TS`／`BDMV`），选择标题或播放列表，跨文件定位并预览 VOB／PGS 字幕。支持不重新编码的剪辑导出，DVD 默认 VOB、蓝光默认 M2TS，也可为兼容轨道选择 MP4／MKV。DVD 支持运行库可处理的 CSS 保护。

播放列表从 GOP 中间接入另一片段时，会明确拒绝跨越该衔接点的无损导出。光盘 M2TS 输出会重新封装，并按导出时间轴重建时间戳。

暂未验证播放项之间轨道布局变化的播放列表，轨道选择以打开标题时探测到的轨道为准。暂不支持光盘菜单、受保护的蓝光及将光盘来源保存到工程。

单独的 VOB 不携带 IFO 字幕调色板，如需在一个文件中保留字幕颜色，可选择 MKV。

DVD 跳转只精确到 VOBU，预览显示的时间可能与实际相差不到 1 秒；导出切点按标记时显示的关键帧定位。

## TS 工具与包结构

- **TS 原始流截取**：按字节范围或包范围直接提取 TS 数据。
- **TS 快速检查**：扫描同步丢失、TEI、连续计数器、PES、PCR、PTS、DTS、音视频漂移和码率变化，并可导出文本报告。
- **TS 包查看器**：逐包查看 188 字节 TS 或 192 字节 M2TS 数据，按包编号、偏移或 PID 导航，并将解析字段与 Hex 字节高亮关联。M2TS 可查看附加头和到达时间戳。
- **TS ES 提取器**：选择一条或多条轨道，去除 TS 和 PES 封装后分别输出原始视频、音频、字幕或数据负载。
- **TS 流过滤器**：保留选定 PID，或按服务拆分文件，同时重建必要的节目表和业务表。
- **TS 流编辑器**：删除轨道或节目、调整标识及 PID，并编辑服务或语言信息，同时保留原始媒体编码。
- **TS 时间轴修复**：分析并安全校正受支持的 PCR 和时间戳不连续问题，不掩盖传输错误或真实丢包。
- **TS 多源修复**：比较同一信号源、同一时间段的兼容录制，在安全匹配的前提下使用正常的 TS 包、PES 或 ES 数据修复损坏区域及大段缺失。
- **TS 二进制合并**：按顺序追加 TS 分片、去除完全相同的二进制重叠，或合并仅连续计数器不同的同源重叠录制。

支持 188 字节 TS 和 192 字节 M2TS 无损剪辑，按实际包结构识别；M2TS 默认输出为 `.m2ts`，保留附加头。快速检查（含批量）、原始切割、包查看器、节目拆分和 ES 提取也支持 M2TS。时间轴修复、流过滤、流编辑器、多源修复和 TS 二进制合并暂仅支持 188 字节 TS；不支持的包长会明确提示。
