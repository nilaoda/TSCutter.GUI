# Appearance and languages

## Themes

Choose from six Windows theme families — Classic, XP, 7, 8, 10 and 11 — with separate light and dark palettes; macOS also offers a macOS appearance with the native title bar. Switch families quickly with **View → Theme**, or choose the light and dark palettes separately in **Tools → Settings**; **Auto detect** follows the system appearance.

Aero and Windows 11 screenshots show the solid fallback; the actual blur or Mica material depends on platform support. Window corners depend on the host system: Aero and Windows 11 themes keep rounded corners on Windows 11 (Build 22000 or later) and use square corners on older Windows.

## macOS

On macOS, every theme provides the native system menu bar. Windows theme families also keep the in-window menu bar for a complete look, while the macOS appearance hides it when the system menu is available. Both menus share commands, shortcuts, languages and check states.

The macOS appearance appears in the theme list only on macOS. It keeps the system traffic lights, rounded corners and shadow, blends the title into the top of the content, moves the application menu to the system menu bar, and uses sidebar blur when available; controls follow the Fluent palette of Windows 11, and the toolbar uses its own monochrome vector icons.

## Interface language

The interface supports English, Simplified Chinese and Traditional Chinese. **Auto detect language** (default) follows the system language; to choose one yourself, turn it off on the General page of **Tools → Settings** and pick the **Current language**.
